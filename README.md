# PPG Signal Filtering Pipeline

A MATLAB-based signal processing pipeline for simulating, filtering, and analyzing photoplethysmogram (PPG) signals with comprehensive noise reduction and performance evaluation.

## Key Features

- **Signal Synthesis**: Generate realistic synthetic PPG signals
- **Noise Simulation**: Add various types of noise for testing
- **Digital Filtering**: Multiple filter implementations for signal cleaning
- **FFT Analysis**: Frequency domain analysis and visualization
- **Performance Metrics**: Quantitative evaluation of filtering effectiveness
- **Comparative Analysis**: Side-by-side comparison of filtering methods
- **Visualization Tools**: Comprehensive plotting and display functions

## Technology Stack

- **Platform**: MATLAB
- **Signal Processing**: Digital Signal Processing Toolbox
- **Analysis**: FFT algorithms, statistical metrics
- **Visualization**: MATLAB plotting and graphics functions

## Project Structure

```
├── mainScript.m            # Entry point and pipeline orchestration
├── synthesizeSignal.m      # PPG signal generation
├── addNoise.m             # Noise addition functions
├── padZeros.m             # Signal padding utilities
├── computeFFT.m           # Frequency domain analysis
├── calculateError.m       # Error computation metrics
├── calculateMetrics.m     # Performance evaluation
├── displayResults.m       # Results visualization
└── plotPPGSignals.m       # Signal plotting functions
```
